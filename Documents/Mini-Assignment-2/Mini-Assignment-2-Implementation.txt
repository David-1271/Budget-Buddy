ROLE-BASED AUTHENTICATION IMPLEMENTATION
----------------------------------------

Backend Authentication Routes:
- POST /api/auth/login: Authenticates users and returns role information
- POST /api/auth/signup: Registers new users as 'user' role (admins are pre-created)

Frontend Role-Based Behaviors:
1. Landing Page Behavior:
   - Unauthenticated users see the home page
   - Admin users are redirected to Budget Planner
   - Regular users are redirected to Transaction History

2. Navigation Control:
   - Protected routes only accessible by authorized users
   - Unauthorized users redirected to unauthorized page

3. Page Blocking:
   - Unauthorized page shows "Not Authorized" message
   - Proper role validation before accessing protected routes

Sample Response Format:
{
  "success": true,
  "user": {
    "id": 1,
    "email": "admin@example.com",
    "firstName": "Admin",
    "lastName": "User",
    "role": "admin"
  }
}
